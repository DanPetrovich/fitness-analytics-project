# Вовлечённость в фитнес-программе

Интерактивный исследовательский дашборд по учебному датасету онлайн-тренировок. Проект отвечает на вопросы варианта 2:

- как меняется вовлечённость по неделям;
- какие типы тренировок популярнее;
- какие тренеры и форматы работают лучше;
- какие видео стоит перезаписать;
- как выбор типа связан с вовлечённостью зрителя.

Все графики связаны фильтрами. Нажатие на неделю, тип, тренера или тренировку пересчитывает остальные блоки. В публичном `data.js` хранятся только агрегаты — без ID пользователей.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.
